'''Wilderness theme''' is a [[House style]] option for a [[player-owned house]].
[[File:Deadman- Annihilation Overview %26 Rewards Blog (6).png|thumb|Concept art of the Wilderness theme style.]]
This house style can be used by owning the [[annihilation blueprints]] and requires level 1 Construction to use in a player's house. The blueprints are a tradeable item that can be purchased from the [[Deadman Reward Store]] for 15,000 [[Deadman points]].

The option to change to the Wilderness theme style is permanently unlocked after redecorating with the blueprints the first time. Upon unlocking the house style, a set of [[Annihilation exit portal blueprints]] are also given which can be used to recolour the exit portal.
