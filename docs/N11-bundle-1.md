[OSRS Wiki Pigeon cage](https://oldschool.runescape.wiki/w/Pigeon_Cage) and [Biohazard](https://oldschool.runescape.wiki/w/Biohazard) establish a quest action. Darkan `src/main/java/com/rs/game/content/quests/biohazard/utils/BiohazardUtils.kt:94–118` checks the quest stage, birdfeed and exact tile, then runs bird projectiles, replaces 424 with 425 and advances the quest. Here Biohazard has only a QuestList/varp entry, no implementation of those prerequisites. Owner/Claude must choose a Biohazard task before building the release lifecycle. Merely turning every cage into 425 would bypass the quest.
