Source: [RS Wiki, Shards of Armadyl](https://runescape.wiki/w/Shards_of_Armadyl), Products table: 100 shards, 77 Crafting, 150 Crafting XP. This is base XP, passed through the server's existing XP route. The 2012 [Tip.It orb entry](https://www.tip.it/runescape/items/view/11701-orb-of-armadyl) independently confirms 77 Crafting for making the orb as well as attaching it. Donor: `C:/RSPS/import-source/donors/darkan/world-server-dev/src/main/java/com/rs/net/decoders/handlers/InventoryOptionsHandler.java:301`: 100 shards -> 21775, success `You combine the shards into an orb.`, shortage `You need 100 shards to create an orb.` The donor omits the skill and XP checks; the Wiki takes precedence for those. Low-level feedback uses the existing shared combination requirement dialogue. Its exact wording is existing server wording, not independently verified retail transcript.

No animation or sound was fabricated: the donor sends neither and no exact retail reconstruction animation/sound id was established. The existing attach sound remains on orb + battlestaff; reconstruction does not attach an orb to another item. Claude must inspect the real visual/audio result with avtrace; this report does not claim a retail-verified silent animation sequence.

The count transaction copies the inventory, removes the recipe inputs and attempts the output in that copy, then commits only changed slots without yielding. A full inventory with exactly 100 shards succeeds because consuming the stack frees its slot. With 101+ and no free slot it refuses without consuming shards or awarding XP. Repeated valid clicks can consume separate batches; a stale click cannot duplicate an orb. Dispatch checks the selected inventory slot again inside the queue. Worn-only and stale-slot clicks do not spend another stack. Shards have no noted form and no worn action in the supplied census; neither a synthetic note nor a worn option is bound. Combat follows the existing generic combination rules. Prebound Combine is preserved using `world.plugins.hasItemOption` before binding.
